Como usar

Fluxo do Roterisador

1. Carregue a planilha da Shopee/SPX.

2. O sistema analisa os dados e mostra a quantidade de pacotes e paradas.

3. Inicie a rota. O número da Parada vem da coluna Stop. Se o mesmo Stop aparecer em endereços diferentes, cada endereço vira um ponto separado no mapa, mantendo o mesmo número de Parada.

4. Toque numa parada para ver os pacotes daquele endereço. A Ordem vem da coluna Sequence.

5. Use ENTREGUE ou ANULAR. O centro e o zoom do mapa são preservados.

6. Use IR ATÉ O LOCAL para abrir o navegador escolhido.

7. Para mostrar o carro, use o GPS. A V15 é particular e tenta usar a localização mesmo quando aberta como arquivo local. Se o navegador bloquear o arquivo, a tela de diagnóstico mostrará a causa.
